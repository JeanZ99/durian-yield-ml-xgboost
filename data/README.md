# Data Directory

## Structure

```
data/
├── raw/          <- Original survey data and data dictionary
├── interim/      <- Intermediate processing files
└── processed/    <- Final Parquet files used by all model scripts
```

## Files in data/raw/

| File | Description | Access |
|------|-------------|--------|
| Cleaned_Durian_Data_ML.xlsx | Farm-level survey data (n=393, Chanthaburi 2021-2025) | Restricted |
| Data-Dictionary-ML.xlsx | Full variable definitions and coding scheme | Public |

## Data access policy

The raw survey data contain farm-level information that may be personally
identifiable and are not publicly shared. Researchers may request access
from the corresponding author for academic purposes.

The data dictionary (Data-Dictionary-ML.xlsx) is publicly available.
